# 永続Wikiと複利効果

LLM Wikiの中核的な差別化ポイント。通常のRAG（[[NotebookLM]]、ChatGPT file uploads等）はクエリ時に生ドキュメントのチャンクを検索し回答を生成する。これは「毎回知識をゼロから再発見する」モデルであり、5つのドキュメントを横断する微妙な質問には毎回断片を探し集める必要がある。何も積み上がらない。

対して永続Wikiは:
- 知識は一度コンパイルされ、最新に保たれる（再導出不要）
- クロスリファレンスはすでに存在している
- 矛盾はすでにフラグされている
- 合成知見はすでに読み込んだすべてを反映している
- ソースを追加するたび、質問するたびにwikiは豊かになっていく

これをKarpathyは **"compounding artifact"（複利的に成長する人工物）** と表現する。100個目のソースはすでにある99ページに接続される。価値は単一の完璧な要約からではなく、ネットワークの蓄積から生まれる。
