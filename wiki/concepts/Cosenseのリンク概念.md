# Cosenseのリンク概念

Cosense（Scrapbox）が持つリンク関連の概念群。2 hop link・赤リンク（空リンク）・大きなリンク・関連ページリスト・リンクサジェスト等。単なる記法ではなく、「ページをリンクで繋ぐことで思考をジャンプさせる」ナレッジグラフ運用思想の体系。

## 用語体系

| 用語 | 意味 |
|---|---|
| リンク | `[ページ名]` ブラケット記法。双方向（順リンク＋逆リンク） |
| 逆リンク | 他ページから自分へのリンク。Cosenseの仕様上片方向でも双方向でも関連ページリストへの影響はほぼ同じ |
| 2 hop link | 別カテゴリのページへのリンクが媒介となって関係性が表現される仕組み。関連ページリストとして表示 |
| 赤リンク | リンク先ページが存在しないリンク。公式用語は「空リンク」。OKF §9では「未記述知識」として許容 |
| 大きなリンク | 逆リンクしているページが大量にあるリンク。関連ページリストが役に立たなくなり、2 hop linkを死なせる |
| 関連ページリスト | ページ下部の関連カード群。2 hop linkの表示場所。原理はただのタグ |
| リンクサジェスト | 入力補完。nishioは「Scrapboxを使ってる主な理由」の1つに挙げる |
| 光る言葉 | 自分の中で「これ」と感じてリンクにしたい言葉。赤リンクは光る言葉を見つけるための取り組み |
| come-fromリンク | howm由来。「<<< aaa」で全出現箇所を呼び集める。1宣言で全出現が親切になる |
| ブラケティング | 言葉を `[ ]` で囲んでリンク化する行為 |

## 2 hop link

shokaiの提唱。「別カテゴリのページへのリンクが媒介となって関係性が表現される、という着眼」。

- ページに2種類を意識して書く: 具体的な物事（タイトルは名詞）のページは本文で抽象概念で説明し、抽象的な概念（タイトルは文章）のページは本文で具体的な物事で説明する
- 「具体→抽象→別の具体」「抽象→具体→別の抽象」の2パターンで思考がジャンプする
- 関連ページリストに「想定外で、忘れてたページなんだけど、見た瞬間コレだよ」とサジェストされるようになる
- 被リンク数が125ページ（villagepumpでの計測）に達する人気概念

## 赤リンクの二面性

**利点（nishioの予測のリンクと不測のリンク不足）**: ブラケティングして赤になった時は「あれ？書いてなかったっけ」となる「不測のリンク不足」で、これはチャンス。書いてなかったなら最低限書く、表現が違うなら同じことかニュアンスが違うかを考えることで理解が一歩前進する。リンクは「結晶化できていない『関係しそう』という弱い情報」であり、事後的にしっかりした情報へ変わる。

**問題点（suto3の蓄積問題）**: 再利用されない赤リンクが年単位で大量に蓄積される。小人さん活動（過去ページのメンテナンス）の際に検索の取りこぼしやリンクサジェスト汚染として実害が出る。一方「絶対に赤リンクを作る自由を守りたい」「再利用されないことが問題であるかは現実ではない」という反論もあり、見解は分裂。

**光る言葉との関係**: 赤リンクは光る言葉を見つけるための取り組み。大量の失敗ののちに光る言葉が見つかり、その失敗ログが赤リンクとして残る。ただし「やたらめったら赤リンクにするのは違う」（はてなダイアリーの全単語リンクの反省）。共同編集では各人の光る言葉のセンス・閾値の違いで競合が発生しうる。

## 大きなリンクと2 hop linkの死

同じページに向かってリンクしすぎると2 hop linkが死ぬ。これは大きなリンクの実害として周知されるべき。Infoboxテンプレート設置ページへのリンクは2 hop linkが発生しないため回避策になる（infobox記法）。「そもそも2 hop linkが死んではいけないだろうか」という根本的問いかけもあり、2 hop linkが死ぬことも含めてページのコンテンツとして意味付けできれば問題ないという立場も存在する。
