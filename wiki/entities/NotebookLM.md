# NotebookLM

GoogleのAIノートブック。ドキュメントをアップロードし、質問応答を行うツール。Karpathyはこれを典型的なRAGシステムの一例として挙げている。

## LLM Wikiとの関係

Karpathyの分類では、NotebookLMは「クエリ時に知識を再発見する」[[RAG]]型であり、[[永続Wikiと複利効果|知識が蓄積する永続Wiki型]]ではない。ChatGPT file uploadsやその他多くのRAGシステムと同じカテゴリ。
