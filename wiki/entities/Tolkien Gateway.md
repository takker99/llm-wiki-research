# Tolkien Gateway

J.R.R. Tolkienの作品に関するファンwiki。KarpathyがLLM Wikiの読書ユースケースの実例として引用。

## 特徴

- 数千の相互リンクされたページ: キャラクター、場所、イベント、言語
- ボランティアコミュニティが何年もかけて構築
- Karpathyの主張: LLMがあれば、個人でも読書中に同様のコンパニオンwikiを構築できる（LLMがクロスリファレンスと保守を担当）
