# llm-wiki-template

LLM Wikiテンプレートの研究・開発を目的としたLLM Wikiです。
KarpathyのLLM WikiパターンとCosense（Scrapbox）コミュニティの知見をingestし、
汎用的で実用的なテンプレートを育てていきます。

## このWikiの目的

- KarpathyのGist、nishioの実践知、villagepumpの議論をingestして知識基盤を作る
- ディレクトリ構成、AGENTS.mdの内容、運用パターンを比較・分析する
- **最終的に汎用テンプレートを出力する。** 配布形式（別リポジトリ / `template/` ディレクトリ / その他）はこのWikiでの検討を通じて決める

## 現状

- raw/ に6件のソースを配置済み
- AGENTS.md に初期スキーマを作成済み
- wiki/ のingestはこれから

## 使い方

このリポジトリをクローンして、LLMエージェントで「ingestして」と指示すれば、
Wikiが育ち始めます。育った結果としてのテンプレートは別途出力予定です。
